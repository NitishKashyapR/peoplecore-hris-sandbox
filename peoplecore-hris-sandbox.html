A — About & Creator

Mission statement

PeopleCore exists to make enterprise HR systems legible. It is a single-file, zero-install simulator where every payroll rule, permission gate, statutory formula and audit event is inspectable — so HR practitioners, engineers and compliance teams can learn exactly how the systems that employ them actually behave.

Nothing leaves this browser: all state is computed and persisted locally, and the platform is distributed as one portable HTML document that runs offline.

D — Data Exchange & Architecture Guide

Tabular roster ingestion (.csv)

CSV files drive bulk employee onboarding and batch updates. Standard columns — name, email, role, department, salary and status — are mapped straight onto worker records, so a whole cohort or a department-wide correction is applied in one pass instead of one manual entry at a time. Every row is previewed and validated before it is committed to the directory.

Enterprise state snapshots (.json)

A JSON snapshot exports the complete sandbox environment — employee profiles, compensation tables, org trees, payroll registers and the immutable audit log — as a single portable document. Restore that document to return the platform to an exact earlier state, switch between prepared scenarios, or migrate the whole dataset to another machine. Snapshots are the supported route for backup, rehearsal and offline hand-over.

Local-first privacy & zero-cloud architecture

Every simulation record, payroll calculation and compliance test runs 100% in-browser against this origin's local storage. There is no account, no API call and no telemetry channel: no employee data, compensation figure or corporate record ever leaves the device. Closing the tab ends the session, and section E below can re-initialise the dataset whenever you want a clean starting point.
