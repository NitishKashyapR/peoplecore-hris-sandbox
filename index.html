Why PeopleCore?

The gap between HR training and HR reality.

Most professionals learn enterprise HRIS on slides, then meet statutory math on their first live payroll run. PeopleCore closes all three gaps at once.

The sandbox problem

Workday, SuccessFactors and Gusto only open up behind expensive enterprise licences or paid test tenants — exactly the access a fresh graduate or a consultant evaluating a stack never gets.

PeopleCore ships the tenant. A full multi-module HRIS with seeded employees, open requisitions, pending leave and a live payroll cycle — free, forever, with zero provisioning.

The compliance reality

Modern HR is applied mathematics: FLSA blended overtime, German social-contribution ceilings, Indian gratuity and EPF, UK PAYE tax codes and NI thresholds. Manual data entry never teaches the formula behind the figure.

The engine computes it live. Switch jurisdiction and gross-to-net, severance, leave standards and payslip disclosures all re-contextualise — with the governing code printed beside them.

The local-first guarantee

Cloud HR tooling means accounts, trackers, tenant costs, uptime dependencies and employee data sitting on somebody else's database — a hard sell for a classroom, a workshop or a personal portfolio.

Zero trackers, zero servers, zero database cost. State persists to localStorage for offline use; export a JSON snapshot and carry the whole company record to another machine.

Module 00 · Executive Command Center

A single-pane operational triage surface: approvals, compliance clocks, coverage gaps and cycle execution — no tab-hopping, no stale spreadsheet.

  • Universal action inbox with SLA badges, countdowns and one-click triage across leave, documents, shifts and reviews.
  • Four telemetry cards — active headcount (W-2 / 1099 split), open requisitions, committed cycle payroll and a live compliance index.
  • Workforce velocity & mobility pulse — recent arrivals against anniversaries, work-authorisation expiries and review windows.
  • Quick actions jump straight into onboarding, leave requests, payroll execution and the audit log.

Individual & bulk workforce provisioning

Hire one worker with a guided wizard, or ten thousand rows through validated ingestion — both routes produce identical, auditable master data.

  • Jurisdiction-aware defaults — the wizard seeds statutory leave entitlement, classification and pay class from the active regime.
  • Row-level CSV validation with a preview/commit gate: valid rows land, invalid rows report the exact failing field, and nothing is silently dropped.
  • Schema-checked JSON snapshots for restore, plus downloadable templates and register exports.
  • Reconciled master data — an ATS conversion fills a real position seat, while manual onboarding seeds jurisdiction-correct leave balances, worksite defaults and a classification-correct pay class.
Live jurisdiction switch

Same register, same workers — switching the regime re-computes withholding, currency, labels and disclosure text.

Multi-jurisdiction statutory engine

Four global economic regimes, calculated by one engine: US · UK · DE · IN.

  • US — federal/state withholding, FICA 7.65%, 401(k) deferral, FUTA/SUTA employer burden.
  • UK — PAYE, employee/employer NI, auto-enrolment workplace pension, statutory payslip rules.
  • Germany — wage tax incl. solidarity surcharge, pension 9.3%, health 7.3%, unemployment 1.3%.
  • India — TDS, EPF, ESIC, professional tax and gratuity accrual on every payslip.
  • Exit settlements too — at-will PTO encashment, UK/EU statutory notice caps and Indian gratuity (15 × Basic × Years) / 26.

Append-only forensic ledger

There is no delete operation. Corrections are recorded as new compensating events, so the record can be defended in a wage claim, a discrimination charge or a SOX control test.

  • Every mutation logs actor, role, timestamp, event type and a JSON payload with before/after values.
  • Typed events across the estate — onboarding, transfers, terminations, leave, payroll runs, SaaS grants, jurisdiction switches, snapshot restores.
  • Bounded retention and export — the ledger caps at 400 events and exports to CSV or JSON for inspection.
  • Statutory retention citations live beside it: IRS 4-year wage records, UK GDPR storage limitation, HGB/AO 6–10 years, Companies Act 8 years.

Studio Audio Lectures & Network Streaming Notice

On-Demand Network Stream

While the entire core HRIS simulation engine, computational formula labs, and 100-question examination suite run 100% offline in client browser memory without any server dependencies, playing the 10 companion studio audio lectures requires an active internet connection. To maintain a lightweight single-file HTML distribution, audio tracks stream on demand from the repository assets rather than being bundled as heavy base64 payloads inside the standalone document.

Under the hood

Data sovereignty by construction.

No backend, no build step, no database server. The engineering choices are the product features: what you cannot send, you cannot leak.

01 · Dependencies

Zero dependencies beyond standard CDNs

Vue 3 (reactive core), Tailwind CSS, Chart.js and Google Fonts — referenced by URL, cached by the browser. No npm, no bundler, no framework build, no API keys.

02 · State

In-browser reactive store, persisted locally

A single Vue reactive document — employees, positions, pipeline, leave, payroll, ledger — is mirrored to localStorage after every mutation. Close the tab, come back next week, the company is exactly as you left it.

03 · Portability

JSON snapshots in and out

One click serialises the entire environment — profiles, compensation, pipeline, leave, payroll and audit ledger — to a schema-checked .json file. Restore it on another machine and the ledger records the restore as an event.

04 · Offline

Runs from a file:// URL, offline

After the first load the runtime is cached to the browser — the built-in asset diagnostic reports “100% OFFLINE READY”. Double-click the file on a plane and the sandbox still boots.

05 · Access control

Three RBAC roles, enforced in the UI

HR Super Admin, HR Manager and Employee each render a different application: locked modules, masked compensation and self-service payslips — the same permission surface enterprise HRIS platforms gate behind a licence tier.

06 · Delivery

One HTML file, self-contained

Markup, styles, script, seed data, the icon sprite and the certificate engine all live in one document — no assets folder, no service worker, no install step. The in-app Settings suite carries the data-exchange and architecture guide next to appearance, storage and danger-zone controls.
